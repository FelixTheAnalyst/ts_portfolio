Overview

This portfolio investigates how risk, structural change, and public behaviour show up in South African financial and economic time series; and how we can responsibly claim to know about it given the data we realistically have access to. Four substantial projects approach this single underlying question from different angles.

What You’ll Find

  • Reflective Commentary — Learning achievements, methodological challenges, ethical considerations, future directions. (1,500 words)

  • Journal — Dated entries documenting progress, difficulties, and insights as the portfolio developed.

  • Code & Data — R scripts, data sources, reproducibility statements, and reconciliation decisions.

  • AI Use Log — Transparent record of where AI assisted this work.

Key Design Decisions

  1. Unified narrative, not four unrelated projects. All four investigate the same underlying question about SA time series from different methodological angles.

  2. Smaller pieces recycled data. A hidden Markov model reanalyses the EAF from Project 2; ARIMA and exponential smoothing use macro series touched by earlier projects. This demonstrates methodological versatility without requiring new data collection.

  3. Honest about limitations. Each project explicitly states what its data and method cannot claim to show; treating limitations as a strength, not a weakness.

  4. Reproducible from the ground up. Code is documented, data sources are transparent, and every reconciliation decision is logged.

Getting Started

Begin with the Reflective Commentary to understand the overarching themes. Then follow the Journal chronologically to see how these ideas developed. Finally, dive into the Projects in order.
